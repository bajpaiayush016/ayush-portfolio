# Ayush Bajpai — Portfolio

A responsive portfolio built with plain HTML, CSS, and JavaScript.

## Folder structure

- `index.html` — page structure and content
- `css/style.css` — styling, responsive layout, animations, and 3D effects
- `js/script.js` — interactions and animation behavior
- `assets/certificates/` — uploaded participation certificates

## Run locally in VS Code

1. Extract the ZIP file.
2. Open the `Ayush_Bajpai_Portfolio` folder in VS Code (`File > Open Folder`).
3. Install the **Live Server** extension by Ritwick Dey if it is not already installed.
4. Open `index.html`.
5. Right-click inside the editor and choose **Open with Live Server**.
6. The portfolio will open in your browser. Save changes in VS Code to see them refresh.

You can also open `index.html` directly in a browser, but Live Server is recommended while editing.

## Before publishing

Review the contact and social links in `index.html` and replace any placeholders with your real details.
Only keep skills and project descriptions that you can confidently explain.
